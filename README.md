# Cybersecurity Portfolio

Hands-on cybersecurity portfolio documenting practical labs, security projects, certification training, network security, defensive security, and penetration-testing fundamentals.

The focus of this repository is not configuration alone, but **implementation, validation, troubleshooting, evidence collection, and technical documentation**.

## Current Work

| Area | Focus | Status |
|---|---|---|
| [CompTIA Security+ SY0-701](Security+/) | Hands-on labs aligned with Security+ objectives | In progress |

Additional sections will be added as documented work is completed.

## Lab Environment

The portfolio is supported by a dedicated virtualized cybersecurity home lab built primarily with **Proxmox**.

Current platforms include:

- Kali Linux
- Ubuntu Server
- Windows 11
- pfSense
- OpenWrt

Tools and services used in documented lab work include:

- UFW
- OpenSSH
- Nginx
- Wireshark

The environment will continue evolving as new security scenarios, monitoring tools, and certification objectives are implemented.

## Documentation Standard

Labs in this repository are documented with an emphasis on reproducibility and evidence. Depending on the exercise, documentation may include:

- Lab objective and environment
- Commands and configuration changes
- Screenshots and technical evidence
- Positive and negative testing
- Log and event analysis
- Troubleshooting and recovery
- Security-control interpretation
- Final validation and observed state
